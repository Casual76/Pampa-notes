## Prioritized findings

No confirmed defect requiring correction. No hypothesis is promoted to a failure or approval condition.

The following adversarial candidates were tested and falsified within the stated fixture scope:

1. **Stale authority before admission/body.** Owner or index changes after real identification but before middleware continuation return 409 without body reads, archive access or job registration. Missing authority, guests and anonymous callers cannot enter alignment. Evidence: whisperx_server.py:1896-1934; test_forced_alignment.py:354-375, :491-503; executed 88-test run. The independent ordinary-ASR handoff probe also rejects stale identification before its body is read.
2. **Same owner, different index during work or access.** Old and newly authenticated callers under the new authority cannot read status/partial or cancel the old alignment job. Queued work does not enter the worker after rebinding; callback and post-work/result fences reject a stale result. Evidence: whisperx_server.py:548-554, :2615-2667, :2684-2692, :2907-2917, :2982-2985; test_forced_alignment.py:239-267, :377-402, :505-548. Independent probes additionally switch after archive.get returns and after _await_work returns a completed mocked result; both reject with account_changed.
3. **Ticket cache and local-token authority confusion.** Ticket/guest cache entries are scoped to the captured owner/index, verification uses that captured index, and a mid-verification rebind cannot seed a valid cache entry. Negative ticket results expire and trigger a fresh verification. Old local-token callers fail after rotation. A new token for the same bound owner/index can still see/cancel that account's old job; a new unbound token cannot see/cancel an old-token job. Refreshed same-account tickets remain valid. Evidence: whisperx_server.py:1793-1820, :1984-2042; test_forced_alignment.py:404-489; independent AuthorityProbes negative-cache/rotation tests. These use synthetic credentials only.
4. **Wrong or substituted original audio / replay.** Upload SHA mismatch rejects even if a correct archived blob exists. Archive bytes are hashed before and after work; corrupted bytes and bytes mutated during alignment reject. Upload/archive handoffs recheck authority; cancellation during upload discards the file and never starts work. Duplicate alignment IDs cannot replace the retained snapshot, including through ordinary ASR registration. Registry expiry/restart is explicitly process-local, and a fresh process identity/fresh validated request is accepted. Evidence: whisperx_server.py:512-554, :2801-2820, :2892-2899, :2941-3000; test_forced_alignment.py:120-134, :550-607, :734-798; independent HttpProbes and upload/archive probes.
5. **UTF-16 versus Python/model character identities.** An input with 398 ASCII characters plus one supplementary character reaches exactly 400 UTF-16 units; 399 plus that character defers without calling the aligner. Split surrogates and lone surrogates reject. Exact original text, punctuation, whitespace, language, part identity and source hashes are retained; invented model text/language is ignored. Unknown lexical characters, lowercasing expansions, decomposed marks not in the dictionary and punctuation-only tokens retain null times. Evidence: whisperx_server.py:2695-2758, :2767-2797, :2867-2883; test_forced_alignment.py:72-118, :196-217; independent MatrixProbes. No Unicode normalization or inferred identity was assumed.
6. **Unbounded or invented timing.** Inclusive 30,000 ms/400 UTF-16 bounds and rejection beyond 1000 windows are tested. The additional probe actually iterates 1000 synthetic windows and checks every align call's input and decode duration; this remains mocked computation. Oversized or absent coarse windows defer, never distribute text over time and never call ASR. A shortened synthetic decode constrains accepted evidence to that actual buffer; an oversized returned decode buffer never enters the aligner. Bad numeric types, nonfinite/low/out-of-range scores, missing/reordered/substituted characters, intra-token reversals, cross-token overlap and split-token windows fail closed. Evidence: whisperx_server.py:2672-2676, :2736-2747, :2761-2797, :2831-2889; test_forced_alignment.py:136-217; independent MatrixProbes. Unknown/unreliable/unmapped timings remain missing with both time fields null.
